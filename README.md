# 🚀 pyTrade3 — Quantitative Automated Stock Trading Bot

`pyTrade3` is an automated quantitative swing-trading bot for US and European stocks built with Python, PyQt6, Interactive Brokers (IBKR TWS/Gateway), and SQLite.
